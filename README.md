## 📱 About

Calculator is a lightweight Android calculator designed to provide
essential arithmetic and scientific functions while keeping the interface
simple and customizable.

## ✨ Features

- ➕ Basic arithmetic operations
- 🔢 Powers and square roots
- 📐 Sin, cos, and tan
- 📊 Logarithmic calculations
- 🕘 Calculation history
- 🎨 Custom button colors
- 🌙 Light and dark themes
- 🔼🔽 Calculation increase/decrease counter
- 📱 Lightweight Android application
